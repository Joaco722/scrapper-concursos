# 📚 Scraper CGE - Concursos Educativos

Script automatizado diseñado para extraer, organizar y facilitar el monitoreo de la información pública sobre los concursos docentes del Consejo General de Educación.

### 🛠️ Tecnologías utilizadas
* **Python**
* **Selenium** (para la navegación automatizada y extracción de datos del DOM)

### 🚀 Características principales
* Navegación automatizada por el sitio institucional.
* Extracción estructurada de los datos de las convocatorias.
* Reducción del tiempo de búsqueda manual de concursos.
